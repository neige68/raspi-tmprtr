raspi/client/ (Ruby) の Python 移植。
raspi-home/try-python/ にて動作確認済みのものを取り込んだ。

v temp.py - DS18B20 温度センサー読み取り (w1thermsensor)
v cputemp.py - CPU 温度取得 (gpiozero + lgpio)
v httpsget.py - HTTPS GET (requests)

o main スクリプト (tmprtr_multi.py) を作る
  * 複数センサーを読み取り POST で送信
  * raspi/client/tmprtr_multi.rb を参照
  * POST: requests.post("url", data={"temp": 25.5})
  * クエリパラメータ: params = {"i": id, "t": temp, "k": key}
    response = requests.get(url, params=params)

o cron 登録スクリプト (tmprtr.crontab) を作る
  * CRON_TZ=Asia/Tokyo を設定

環境構築 (raspi 上):
  uv python install 3.13
  uv sync
  sudo apt install swig python3-dev liblgpio-dev   # lgpio のビルドに必要
